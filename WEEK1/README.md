# Output and Variables
print and echo are used to display text on a webpage.
Variables in PHP start with $.
Example variables include:
$studentName
$studentAge
$course
Variables store information that can be used later in the program.
2. Constants
A constant stores a value that does not change.
PHP uses define() to create a constant.
#  If / Elseif / Else
Conditional statements are used to make decisions.
The program checks the student's mark and displays a message:
90 or above: Excellent work
70–89: Very Good
50–69: You passed
Below 50: You failed

#  Switch Statement
switch is used when one variable needs to be compared with several possible values.
In the example, $day is checked against different days.
Each case gives a different message.
break stops the switch after a matching case.
default runs when no case matches.
